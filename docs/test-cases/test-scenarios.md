# TokoMart Test Scenarios — Web Platform

> **Scope:** Web only (`frontend/` — React). Generated by `/create-scenarios generate test cases for web only`.  
> Mobile-only flows (wishlist, cart checkbox selection, auth gate) are excluded. See `docs/test-cases/test-scenarios-mobile.md` when mobile suite is generated.

---

## P0 Smoke Block

| # | Platform | Flow | Automation |
|---|----------|------|------------|
| S1 | Web | Login → add to cart → checkout COD → order appears in history | Playwright |
| S2 | Mobile | Login (reference `frontend-mobile/patrol_test/login_test.dart`) → browse → cart visible | Patrol — **out of scope for this web suite** |
| S3 | Web | Become seller → create simple product (TC-042) → create variant product (TC-064) | Playwright |
| S4 | Web | Cart with items from 2 sellers → checkout → 2 separate orders in history | Playwright |
